# Comic character asset

spider-comic-reference.png is the original transparent PNG served by https://www.pngaaa.com/api-download/3184398 and shown at https://www.pngaaa.com/detail/3184398 . The source page labels the image Non-commercial Use. It matches the comic illustration supplied by the user as the pose and texture reference. Downloaded intact; no watermark or background was removed. The source raster is 722 × 961 pixels with transparent padding. Spider-Man is a Marvel character; the host does not establish a commercial-use license.

The app renders the original image through SVG clips/masks and animates the head and free-forearm layers. The upper, pre-drawn web is clipped in the view so a computed web line can join the same hand/foot pins during motion.

Two image-generation attempts for an original illustration were rejected; no generated assets were used.
